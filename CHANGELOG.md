# Changelog

## [0.2.0] - 2026-10-01

- Add typed `instrument(target, { namespace, contracts })` registration for class instances and module objects. Business methods stay plain; function wrappers remain compatible.
- Support own functions, arrow fields and inherited public methods without changing shared prototypes. Preserve receivers, private state, synchronous results and asynchronous outcomes.
- Allow multiple instances to share a reviewed path; conflicting declarations remain incomplete and a passing call cannot erase drift.
- Make registration the recommended onboarding path and include a runnable comparison of wrapper, class and module styles.
- Add a timed, resumable pilot study covering all seven feedback worksheet measures, counterbalanced task orders and Markdown/CSV/JSON reports. Synthetic feedback is explicitly labeled; human preference remains unmeasured.
- Validate the installed package examples, interactive pilot flow and repair cycles across the CI runtime matrix. Keep the Python-compatible wire schema at 0.1.0.

Experimental alpha. GitHub releases include a validated tarball; npm publication is separate.

## [0.1.0] - 2026-09-30

- Introduce the Node.js TypeScript SDK: Check, Contract, Policy and typed sync/async wrappers.
- Preserve Python schema 0.1.0 declaration hashes, deterministic sampling, check outcomes and privacy defaults.
- Add a bounded protobuf OTLP/HTTP watcher with gzip, chunked requests and session deduplication.
- Add a local supervisor, fresh scenario runner, 0/1/2 gate and synchronous Claude Code hooks.
- Include an executable pricing repair example, cross-language fixtures and installed-tarball checks.
- Mirror Python repository ownership, Pages, review protection and release workflow conventions.

Experimental alpha; no npm release has been published. See docs/PORT.md for deliberate language differences.
